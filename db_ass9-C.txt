
QNO 3:
A library maintains a record of books and their authors. If an author is removed, their books should not be deleted, but their author information should be set to NULL.

Tasks:
Create an Authors table:

AuthorID (PRIMARY KEY, AUTO_INCREMENT)
AuthorName (NOT NULL, UNIQUE)
Create a Books table:


mysql> create table authors(authorid int primary key auto_increment,authorname varchar(50) not null unique);

mysql> desc authors;

| Field      | Type        | Null | Key | Default | Extra          |
+------------+-------------+------+-----+---------+----------------+
| authorid   | int         | NO   | PRI | NULL    | auto_increment |
| authorname | varchar(50) | NO   | UNI | NULL    |                |
+------------+-------------+------+-----+---------+----------------+



BookID (PRIMARY KEY, AUTO_INCREMENT)
BookTitle (NOT NULL, UNIQUE)
AuthorID (FOREIGN KEY )


mysql> create table books(bookid int primary key auto_increment,booktitle varchar(50) not null unique,authorid int,foreign key(authorid) references authors (authorid) on delete set null);
