# Student Marks Tracker

A simple Python basic project that demonstrates:

- **List:** the list of students and each student's marks
- **Dictionary:** a student's `name` and `marks`
- **Loop:** `for` loops for students and marks
- **Module:** `data.py` and `reports.py`
- **Package:** the `school` folder (contains `__init__.py`)

## Run

Open a terminal inside this folder and run:

```powershell
python main.py
```
