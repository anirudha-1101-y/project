@#@ PDBC - (PYTHON DATABASE CONNECTIVITY)-->
Python database connectivity is mechanism that enable python application to communicate with relational databases using standarise api 
--> python follow a standard called PYTHON DB-API2.0 .
--> This ensure that different database module behave similarly
--> Before DB-API every database had its own way of connecting and executing query 
--> DB-API provides a common standard code become portable , consistent , easy to maintain
--> It is not a library it is a set of rule 


ADVANTAGES OF DB-API :-

1. database independence 
2. easy to switch
3. standard coding type 
4. secure (it support parameterize query )
5. reduce development time

PYTHON DATABASE MODULE- (drivers)

1. To connect python with database we use specific libraries
 for example-
           
MySQL        mysql-connector-python,pymysql
PostgreSQL psycopg2
SQLite sqlite3 (built-in)
oracle cx_Oracle
MongoDB pymongo
 

2. A database driver or module is a python library that allow your program to connect to a database , execute sql queries and fetch result 

3. This modules follow PEP249 that why their structure is similer

4. PEP249-- python enhancement proposal

5. this proposal tells how python database module should behave and what method they must provide 


@## DATABASE CONNECTIVITY ARCHITECTURE-

user/application program --> DB-API 2.0 Interface(PEP249) ---> database driver (mysql-connector) --> database server(MySQL/PostgreSQL)--> data storage

work flow--

User / Application Program
          ↓
    DB-API 2.0 Interface
        (PEP 249)
          ↓
     Database Driver
   (mysql-connector)
          ↓
     Database Server
   (MySQL / PostgreSQL)
          ↓
      Data Storage
